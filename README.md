# Social Media App - Backend

A RESTful backend API for a Social Media Application built using the MERN stack. 
This backend provides user authentication, post management, likes, comments, and other social media features.

## 🚀 Features

- User Registration & Login
- JWT Authentication
- Secure Password Handling
- User Profile Management
- Create Posts
- Get All Posts
- Edit Posts
- Delete Posts
- Like / Unlike Posts
- Add Comments
- Edit Comments
- Delete Comments
- Image Upload
- MongoDB Database
- RESTful APIs
- Error Handling & Middleware

## 🛠️ Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT (JSON Web Token)
- bcrypt
- Cloudinary
- Multer
- REST API
- JavaScript (ES6+)
